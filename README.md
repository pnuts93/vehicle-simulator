# Vehicle Simulator

Personal project to experiment with 3D Graphics and physics engines.

## Phase 1
- Render a simple cube (plus simple geometries for reference)
- Make it movable via key-bindings
- Let camera follow cube
- Manipulate vehicle direction and camera offset

## Phase 2
- Load own 3D model
- Add vehicle options
- Add physics
- Add menu and enrich UI

## Phase 3
- Add terrain generation
- Polish application
